# FinSphere 💜

Plataforma Full Stack para gerenciamento financeiro pessoal.

O projeto está sendo desenvolvido com o objetivo de aplicar conceitos de desenvolvimento Full Stack, arquitetura de APIs, persistência de dados, segurança, testes e cloud computing.

## 🚀 Tecnologias

### Back-end
- Java
- Spring Boot
- Spring Data JPA
- Spring Security
- Maven

### Front-end
- Angular
- TypeScript
- HTML
- CSS

### Banco de Dados
- PostgreSQL

### Cloud
- AWS

### DevOps
- Git
- GitHub
- Docker
